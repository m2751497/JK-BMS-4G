# 截图存放目录

README 简介页展示 4 张本项目网页截图,文件名固定,截图后放到本目录并覆盖同名文件即可(无需改 README):

| 文件 | 内容 | 建议 |
|---|---|---|
| `gps.png` | 📡 GPS 页(地图定位 + 速度/续航卡片) | 已定位状态 |
| `bms.png` | 🔋 BMS 页(电池状态 + 单体电压/内阻/容量) | BMS 已连接、有数据 |
| `track.png` | 🚗 轨迹页(历史轨迹回放 + 统计) | 有轨迹线 |
| `settings.png` | ⚙️ 设置页(上报间隔/高德/账号) | 全貌即可 |

**截图方法**:浏览器登录 `http://你的域名` → 依次切换到 4 个 Tab → 截图(建议窗口宽度 ≥ 1000px,PC 浏览器 F12 切移动端模拟也行) → 保存为对应文件名放到本目录。

> 目录只存放图片,不要放其他文件;图片会随仓库发布到 GitHub。
