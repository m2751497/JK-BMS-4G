========================================
 ESP32-S3 4G 网关固件 v2.21 烧录说明
========================================

【你的板子: ESP32-S3 Super Mini 4MB Flash + 2MB QSPI PSRAM】
→ 选 QSPI 版(PSRAM 生效, 推荐)

一、三个 PSRAM 版本(编译参数不同, 功能完全一样)
  1. esp32s3-gateway-v2.21-QSPI-4MB-OTA.merged.bin   ← PSRAM=QSPI (你的板子用这个)
  2. esp32s3-gateway-v2.21-OPI-4MB-OTA.merged.bin     ← PSRAM=OPI
  3. esp32s3-gateway-v2.21-NOPSRAM-4MB-OTA.merged.bin ← PSRAM=Disabled (无 PSRAM 板子)

二、首次烧录
  - 文件: 对应版本的 *.merged.bin (4MB 全量, 含分区表)
  - 工具: Flash Download Tool 或 esptool, 地址 0x0 全量刷
  - 分区表: 4MB 双 OTA (app0/app1 各 1.94MB, 无文件系统)

三、后续升级 (OTA, 免拆机)
  - 连 ESP32 Web 后台 (192.168.4.1) → 固件升级 → 上传对应版本的 *-OTA.bin
  - 成功自动重启, 失败自动回滚

四、v2.21 要点 (BLE 基于中继完整版 v9.60)
  - ble_svc_gap_init 崩溃根治: setup 即启动广播保持 active (v9.57), 不再有任何运行时广播重启
  - 防抢连: BMS 未连接时 onConnect 回调直接拒绝客户端 (v9.57, 替代隐身停广播)
  - 广播恢复: 5 客户端连满停广播, 断开后自动恢复 (v9.59)
  - MTU 补协商: MTU<100 先 exchangeMTU 异步补协商, 免断开重连 (v9.60, C3 连接提速)
  - 回调安全: notifyCB/parseCellInfo 内不查 NimBLE API, RSSI 查询 5s 限流, 自维护计数 (v9.33/34)
  - BMS 上报按电流+按页面: 仅网页停在 BMS 页才 2s 高频; 其他页/离线按 track
    (充/放电 |I|>=0.3A 30s 上报供续航学习, 停放停报零流量)
  - GPS 只看移动/静止: 移动 2s 实时 / 停放≥60s 停发, 30s 本地探测 (v2.11)
  - Web 后台 = 中继 v9.55 布局: 协议模式/电芯帧偏移/WiFi自动关闭可配置 + 手动扫描 + OTA 升级
