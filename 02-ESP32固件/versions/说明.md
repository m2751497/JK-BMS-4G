# 固件版本历史归档

本目录保存每个版本的完整固件源码 (`esp32s3-gateway_vX.Y.ino`),可随时回溯/对照。

## 归档列表

| 文件 | 版本 | 要点 |
|---|---|---|
| `esp32s3-gateway_v2.21.ino` | v2.21 (当前) | 对照 v9.60 补齐 5 处:parseCellInfo len<190 防御 + RSSI 5s 限流 + notifyCB 诊断用自维护计数 + 删重复 pushBMSData + buildBMSJson reserve |
| `esp32s3-gateway_v2.20.ino` | v2.20 | 合入中继 v9.60(含 v9.57-59):setup 即广播根治 ble_svc_gap_init 崩溃 + onConnect 拒绝防抢连 + 健康检查按客户端数(v9.59 恢复) + MTU 补协商 exchangeMTU |
| `esp32s3-gateway_v2.19.ino` | v2.19 | BMS 上报按电流+按页面:仅网页停在 BMS 页才 realtime 2s;其他页/离线按 track(充放电 \|I\|>=0.3A 30s 供续航学习, 停放停报) |
| `esp32s3-gateway_v2.18.ino` | v2.18 | 后台按 v9.55 布局全面修复(按键/状态/扫描全有效, 去日志区, OTA 移底部) + 修 ble_svc_gap_init 断言崩溃 + 三版 PSRAM 固件 |
| `esp32s3-gateway_v2.17.ino` | v2.17 | 后台按 v9.55 修复 + ble_svc_gap_init 崩溃修复(版本号仍 v2.17) |
| `esp32s3-gateway_v2.16.ino` | v2.16 | 合入 v9.55 功能(协议模式 0/1/2 + WiFi 自动关闭开关 + blePin) + 电芯帧偏移可配置 |
| `esp32s3-gateway_v2.15.ino` | v2.15 | BLE 合入中继完整版 v9.43 全部修复(FIX-22~27 + 扫描退避/MTU 降级/隐身广播/命令缓存/手动扫描) |
| `esp32s3-gateway_v2.14.ino` | v2.14 | 适配 4MB Flash(双 OTA 分区) + Web 后台网页 OTA 固件升级 + 重启原因记录 |

## 归档规则(以后每次发布新版本)

1. 发布新版本 vX.Y 时,将最新 `02-ESP32固件/esp32s3-gateway/esp32s3-gateway.ino`
   复制为 `02-ESP32固件/versions/esp32s3-gateway_vX.Y.ino`
2. 同步更新本表(新增一行)
3. 固件头部注释版本号、Web 后台右上角版本号、`firmware/` 产物文件名、
   `README.md` / `计划书.md` / `部署清单.md` 同步到 vX.Y
4. 归档文件仅供回溯对照,Arduino IDE 打开需放回同名文件夹
