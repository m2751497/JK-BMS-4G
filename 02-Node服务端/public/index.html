ℹ️ 说明
· 轨迹由 GPS 模块按间隔上报自动记录（移动 2s 实时 / 静止自动停发；速度≥3km/h 且位移≥30m 判运动，防漂移）
· 里程 = 相邻轨迹点球面距离累加（haversine）
· **每次行程单独统计**：相邻轨迹点间隔超过 5 分钟即视为新行程（停车/关机断开）
· 行驶时长 = 移动段时间累加（相邻点位移 >20m 才算移动，停车原地不计）
· 网页关闭后 GPS 移动时仍 2s 记录轨迹（静止停发），里程与续航学习不受影响
· GPS 间隔可在「⚙️ 设置」页调整，调快轨迹更密集

📶 流量用量参考
· GPS：移动 2s 实时 / 静止自动停发（网页开/关一致），车辆移动自动恢复
· BMS：网页打开 2s 实时（充/放电/停放一致），网页关闭 30s（保里程与续航学习）
· GPS 2s ≈ 55KB/小时；BMS 2s ≈ 630KB/小时；网页关闭后 BMS 30s ≈ 0.36MB/天
· 按每天开网页 2 小时估算：约 35MB/月，300MB 套餐余量充足
· GPS/BMS 间隔可在上方「刷新频率设置」调整（1~300 秒）
